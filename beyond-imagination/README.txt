1. Add your previous original artworks to the artworks folder.
2. Open index.html in VS Code. Find const artworks and add one object per artwork, following the commented example. Save and preview in a browser.
3. Upload the project folder contents to a GitHub repository. Import the repository into Vercel as a static project (Framework Preset: Other). Deploy.
4. Check the public URL in a private browser window. Use it in the portfolio field only after your previous works are visible.
Keep private contact details off the site. Do not publish the current competition draft unless you choose to.
